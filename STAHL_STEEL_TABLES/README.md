# STAHL STEEL TABLES IN PYTHON
# جدول اشتال مقاطع فولادی در پایتون
The script `STEEL_SECTIONS.py` has three parts. The first is a large block of data, `_RAW`, which holds every table from the Excel file as a dictionary per family (IPE, INP, IPB, UNP, angles, tubes, cast IPE and rebar). Each family stores its designation column name, its column headers, its units, and its rows as tuples, so the numbers sit directly in the code and nothing is read from Excel at runtime. Just after the data comes `SOURCE_CORRECTIONS`, a list recording each typo I fixed along with the original Excel value. The second part is a small engine built around a `Family` class, which wraps one table and offers `get()` to fetch a section as a dictionary, `select()` to filter rows with your own condition, `records()` for all rows as dictionaries, and `to_dataframe()` for pandas. Lookups pass through a `_key()` helper that strips spaces, ignores case and drops a family prefix, which is why `"IPE 200"`, `"ipe200"` and `200` all find the same row. The `FAMILIES` dictionary builds one `Family` object per table, and `ALIASES` maps short names like `"sq"` or `"rect"` to the full family names. The third part is a set of convenience functions: `get(family, designation)` for quick lookups, `lightest(family, Wx=500, ...)` to find the lowest-mass section whose properties all meet your minimums, `to_si()` to convert the cm-based table values to metres, and `show_profile()`, which prints a section's properties and replaces your old function without needing IPython. Running the file directly prints the row count for each family and a sample IPE 200 lookup, which serves as a quick self-test.
